# 对照品标准物质说明表生成

## 使用范围

用户已请求生成或更新说明表时直接执行，不因上传文件或文件名包含 COA、Batch 等关键词主动追问。不重复确认已明确的生成请求。

## 读取 COA

优先提取 PDF 文本；仅扫描页或文本提取不可靠时使用 OCR。使用项目既有、已授权的 OCR 集成，不因本 skill 固定要求某个外部供应商，也不读取或输出真实凭据。外部 OCR 不可用时说明未提取范围，继续处理可可靠读取的内容。

提取以下关键字段：

| 字段 | 说明 |
|:---|:---|
| 药品名称 | Product Name / Description |
| 对照物质名称 | Substance Name / Chemical Name |
| 批号 | Lot No. / Batch No. |
| 生产厂家 | Manufacturer / Supplier (COA来源公司) |
| 英文名 | English Name / Synonyms |
| 有效期 | Expiration Date / Retest Date |
| CAS号 | CAS Number |
| 分子式 | Molecular Formula |
| 分子量 | Molecular Weight |
| 含量 | Assay / Purity (%) |
| 贮存条件 | Storage Condition |

## 核验与修正

- 以 COA 原文为批次事实来源，先检查字段完整性及相互一致性。
- 仅对缺失、矛盾或用户明确要求核验的字段查询可靠来源；公开产品资料不能替代该批次的含量、有效期等事实。
- 供应商批号规则仅在有可靠规则来源且本次需要核验时检查；无法核验时明确标注，不推断规则或反复搜索。
- 分子式下标、空格等不改变含义的格式规范化直接完成，无需再次确认。
- 公司身份、含量、有效期等事实存在冲突时，保留原文并集中询问需要用户决定的字段，不擅自覆盖。等待期间继续模板准备及无争议字段填写；争议未解决前不得将其标为已核实或交付为正式完成件。
- COA 未明确提供的数据保持空白，并在交付说明中列出；不要为填满模板编造数据。

## 生成与完成

1. 使用 `assets/对照物质说明表模板.docx`，按以下映射及格式填写可靠数据，保留模板样式。
2. 批量完成编辑后检查字段、格式和实际渲染结果；修复缺失、截断、溢出等实际缺陷后复验受影响页面，不为主观美化反复重做。
3. 内容与模板要求满足且无未解决事实冲突时，保存并交付 Word 文档，简要列明空缺或无法核验的字段。交付前发现实际缺陷时直接修复并复验，不重复请求生成授权。

## 固定信息配置

以下信息在所有说明表中保持不变（由部署方通过环境变量或部署配置提供，禁止写死个人隐私信息）：
- **提供单位**：珠海保税区丽珠合成制药有限公司
- **经办人签名**：（经办人姓名，由部署配置提供）
- **联系方式**：（联系电话，由部署配置提供）

## 格式规范

生成的Word文档遵循以下格式：
- **中文字体**：宋体 小四（12pt）
- **西文字体**：Times New Roman 小四（12pt）
- **行距**：单倍行距
- **对齐方式**：垂直居中
- **分子式数字**：下标格式

## 填写位置映射

| 坐标 | 填写内容 |
|:---|:---|
| R1C2-4 | 药品名称 |
| R2C2 | 对照物质名称 |
| R2C4 | 批号 |
| R3C2-4 | 来源（COA生产厂家，经核实后的完整名称） |
| R1C2 | 英文名 |
| R1C4 | 有效期 |
| R2C2 | 分子式（数字下标） |
| R2C4 | 分子量 |
| R5C2-4 | 使用范围（勾选"含量测定"） |
| R6C2-4 | 含量数值 |
| R7C2-4 | 贮存条件（根据COA勾选） |
| R8C2-4 | 使用方法（勾选"直接折算"） |
| R2C2-4 | 提供单位（固定：珠海保税区丽珠合成制药有限公司） |
| R3C2 | 经办人签名（由部署配置提供） |
| R3C4 | 联系方式（由部署配置提供） |

## 注意事项

- **来源（R3C2-4）**：填写经核实后的COA生产厂家完整名称
- **提供单位、经办人、联系方式**：使用固定信息
- **分子式**：数字必须设置为下标格式
- **复选框**：使用标准字符 □ 和 ☑
- **COA中无明确数据的字段**：保持空白，不擅自填写
- **事实冲突**：按上述核验规则集中确认；纯格式规范化无需确认。
