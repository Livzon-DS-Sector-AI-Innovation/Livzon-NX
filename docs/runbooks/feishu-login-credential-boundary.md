# 飞书登录凭证收束

根目录 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` 只用于飞书登录及部门、用户通讯录访问。代码不再为消息、业务多维表同步或事件消费者提供这组凭证作为默认值。

## 当前模块行为

| 功能 | 凭证来源 / 当前行为 |
| --- | --- |
| 飞书登录、部门/用户通讯录 | 保留根目录登录应用配置及原有身份模块流程 |
| HR 同步和通知 | HR 数据库中的飞书应用配置；不再从登录应用自动初始化或回退 |
| 质量同步和通知 | 质量数据库中的飞书应用配置；不再自动复制登录应用 |
| 仓储数据读取、写入与事件订阅 | 仓储自己的启用应用配置；未配置时不启动订阅 |
| 设备群通知 | 已有 `EQUIPMENT_FEISHU_APP_ID` / `EQUIPMENT_FEISHU_APP_SECRET` |
| 安全业务 | 保持原有独立安全应用，不受本次修改影响 |
| FA 酸化过滤独立同步脚本 | 使用生产模块已有 FA 应用配置；未配置时在读取和覆盖数据前终止 |
| 注册证书到期提醒 | 暂停生成发送任务；直接调用发送返回 503；不写入已发送记录 |
| 采购飞书同步 | 暂停；同步启动、数据源探测返回 503；保留本地物料目录查询 |
| 其他未传业务凭证的旧通用客户端（包括产品多维表同步） | 无凭证时停止请求，不能借用登录应用；后续需显式接入模块凭证 |

HR、质量通知遇到平台登录用户的 `open_id` 时，优先转换为企业 `user_id`，其次使用企业邮箱。无法转换时不发送；不能把登录应用的 `open_id` 直接当成另一个应用的用户标识。历史卡片仍属于原发送应用，新业务应用不保证能够更新这些历史卡片。

## 部署检查

1. 在模块设置中核对已有业务应用配置；如果历史版本曾把登录应用复制到 HR 或质量数据库，应由管理员替换为独立业务应用，或先停用该模块集成。本次不会读取或清理数据库中的真实密钥，也不会覆盖现有配置。
2. 在飞书开放平台对登录应用收回消息、多维表格等业务权限，仅保留登录和所需通讯录权限；发布审核通过后生效。登录 OAuth 重定向地址保留。业务事件订阅应配置在对应业务应用，不能挂回登录应用。
3. 为业务应用配置其实际所需权限、通讯录数据范围和可用范围；需要跨应用通知时保证可取得企业用户标识。检查表格协作权限和机器人所在群。
4. 重启后端使代码生效。分别验证登录、部门和用户同步；再验证已配置业务模块的同步及通知。注册证书和采购恢复开发前维持停用。

代码边界不等于飞书平台权限已撤回。真实 `.env` / `.env.local`、飞书控制台和数据库配置均未被本次修改。环境模板仅更新用途说明，未新增变量；不涉及数据库结构或 OpenAPI Schema 变化。
