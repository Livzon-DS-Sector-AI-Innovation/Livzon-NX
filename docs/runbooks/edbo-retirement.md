# 实验优化功能下线

EDBO+ 实验优化功能已下线。研发项目、工艺优化、中试工作流和 ICH 分析保留。

- 删除 `/rd/bayesian` 页面及两个 `/api/v1/research/edbo/*` 接口。
- 开发和生产 Compose 不再启动或依赖 EDBO；镜像构建和发布包不再包含该组件。
- 菜单迁移仅停用系统默认的 `rd:bayesian` 菜单，不删除用户自定义菜单。
  若管理员另建了指向旧页面的自定义菜单，应在菜单管理中停用。
- 保留 `research` schema 下既有实验优化表、ORM 映射和迁移历史，防止数据丢失及
  后续自动迁移误判为删表。保留这些表不要求运行优化容器或安装其依赖。
- 菜单迁移回退不自动启用菜单，避免覆盖管理员此前的停用决定；恢复旧版本时需
  由管理员确认后启用。

已有部署升级时，先执行数据库迁移，再启动新版本。旧部署的 EDBO 容器不会因
Compose 删除服务定义而自动消失，应确认名称后单独停止并删除，避免使用全局清理
命令。镜像按明确标签单独处理，不删除共享构建缓存或其他服务的数据卷。
